# World Cup 2026 Predictor Frontend

Independent Next.js frontend for exploring tournament predictions. It currently uses typed mock data and does not call an API or modify the Python backend.

## Start locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run lint` and `npm run build` before shipping changes.

## Structure

- `app/`: App Router pages and global layout, including Overview, Groups, Bracket, Matches and Compare.
- `components/`: feature components grouped by domain, plus shadcn/ui primitives.
- `lib/types/`: shared TypeScript contracts for Python-generated prediction data.
- `lib/data/`: the data-access boundary and temporary mock dataset.
- `public/data/`: destination for static JSON generated by the Python backend.

## Conventions

- Pages and layouts are Server Components by default. Add `"use client"` only when browser behavior or a client-only library requires it.
- UI primitives live in `components/ui/`; feature-specific components live in their domain folder.
- All tournament data is accessed through `lib/data/load-tournament-data.ts`.
- Probabilities are represented as numbers from `0` to `1`.
- Keep backend integration static and JSON-based until an API is explicitly introduced.
